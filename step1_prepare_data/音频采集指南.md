# 音频采集指南

本仓库以单音采样的线性叠加构造多音监督信号（时间、音高、力度由合成过程写入，无需人工听写）。采集物须为孤立击奏、音高与文件名一致的干净单音。

---

## 1. 采集规格

原始音频经预处理后统一为 16 kHz（采样率，每秒采样点数）、单声道、16-bit PCM（脉冲编码调制，未压缩整数波形）的wav文件。输入为下列形态之一。

### 1.1 数据格式

| 项 | 规定 |
|---|---|
| 容器 | `.wav` 或 `.aif` / `.aiff` |
| 形态 A | 半音阶长文件：同一音轨内按半音（相邻两律的音程）升序逐音击奏，音间保留静音 |
| 形态 B | 逐条单音：一文件一音；或以 CSV 给出 `path,midi,dynamic,timbre`（见 `examples/session_sheet.example.csv`） |

排除：滚奏、闷音、滑奏、双音、口令及节拍器泄漏。

### 1.2 信号规格

| 项 | 原始 | 训练输入（脚本转换） |
|---|---|---|
| 采样率 | 44.1 / 48 / 96 kHz | 16 000 Hz |
| 声道 | 单声道或立体声 | 单声道 |
| 位深 | 16 或 24 bit | 16-bit PCM |
| 电平 | 全场固定输入增益；禁止响度归一化 | 合成阶段按片段峰值归一 |

采集环境话筒靠近乐器，减少房间反射造成回响。最好在专业的演奏间录制。

### 1.3 音频采集覆盖要求

乐器从最低音到最高音，**每个键都要有录音**，中间不要跳过。最低音、最高音要和本目录 [`config.py`](config.py) 里的 `MIDI_LO`、`MIDI_HI` 对上（这两个数就是音高编号的下限和上限，例如马林巴常用 36–100，大约 C2 到 E7）。每次音频采集，输出一个文件对应一个力度下的半音阶，注意每个半音演奏之间需要有静音时间作为间隔，否则后期无法拆分数据进行训练。

| 项 | 最少 | 更好 |
|---|---|---|
| 音高 | 每个音至少 1 条 | 所有音都有 |
| 力度 `dynamic` | 至少录一档中等力度 `mf` | 再加轻 `pp`、重 `ff` 两档 |
| 音色 `timbre` | 1 种敲法/拾音就够训 | 2–3 种（例如不同槌、不同拾音位置）；留一种不参加训练，只用来检查模型有没有死记这一种声音 |
| 同一音同一力度 | 录 1 遍 | 录 2–3 遍，听一听，留清楚的 |

怎么弹：

- 一次只打一个音，打一下就停，不要滚奏、不要两个音一起响。
- 声音自然变轻的过程（余振）要录完；等几乎听不见了，再打下一下。低音大约隔 2 秒以上，高音大约 0.8 秒以上。
- 换槌、换力度就另开一场录，不要混在同一条音轨里乱切。
- 弹错了整段重录，不要靠后期降噪凑合。

### 1.4 文件名

半音阶长文件（由文件名解析 MIDI）：

```
<乐器>.<音色>.<力度>.<音域>.wav
```

力度取值限于 `pp` / `mf` / `ff`。音名采用科学音高记号（如 `C4`、`F#3`、`Bb2`）。`C2B2` 表示 C2 至 B2（一个八度、12 个半音）；单音记为 `C7`。

```
Guitar.bridge.mf.E2D3.wav
Piano.felt.pp.A0B0.wav
Xylophone.hard.ff.C5.wav
```

已切分单音亦可为 `<音名>.<音色>.<力度>.wav`，例如 `C4.yarn.mf.wav`。

## 2. Iowa MIS 训练流程

[University of Iowa MIS](https://theremin.music.uiowa.edu/MIS.html)（爱荷华大学乐器采样库）按上述约束采集马林巴：消声室、音域内半音覆盖、三档力度、三种槌（yarn 纱槌、cord 绳槌、rubber 胶槌）、全场增益固定。公开发布为 16-bit/44.1 kHz 半音阶长文件，以及 24-bit/96 kHz 逐音压缩包。本仓库不附带该音频。

训练步骤：

1. 获取 yarn / cord / rubber × pp / mf / ff 的半音阶 `.aif`；不含 roll（滚奏）与 deadstroke（闷音）。
2. 按静音切分为单音，重采样为 16 kHz 单声道，建立索引 `{wav, midi, dynamic, timbre}`。
3. 以基频估计填写 `winner_midi`（质检所得实际音级）；与标称 `midi` 不一致的样本丢弃。每一 MIDI 保留清晰度最高的 7 条（3×3 共 9 条中剔除 2 条）。
4. 按和弦模板将单音合成为 8 s 片段。训练集使用 cord 与 yarn，验证/测试集留出 rubber。
5. 在合成集上训练；若有目标乐器的干净独奏，则以模型低阈值输出为伪标签（未经人工校对的自动标注）微调。

Iowa 马林巴音域为 C2–C7（MIDI 36–96）。更换乐器须按第 1 节重建单音库并重训，不得复用马林巴权重。
